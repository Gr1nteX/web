# Розв'язування СЛАР методом Гауса

Веб-застосунок для розв'язування систем лінійних алгебраїчних рівнянь методом Гауса з вибором головного елемента. Обчислення виконуються у фоновому режимі, користувач бачить хід виконання задачі, може скасувати її та переглянути історію результатів.

## Можливості

- реєстрація та вхід (JWT, паролі зберігаються як bcrypt-хеші);
- задача: випадкова система заданого розміру (з seed) або система, введена вручну;
- обмеження трудомісткості: кількість невідомих і максимальний час обчислення;
- хід виконання у відсотках з назвою етапу;
- скасування задачі в черзі або під час виконання;
- обмеження кількості одночасних задач і розміру історії;
- задачі, їх стан і результати зберігаються в PostgreSQL.

## Технології

- Backend: Python, FastAPI, SQLAlchemy, NumPy
- База даних: PostgreSQL
- Frontend: HTML, CSS, JavaScript
- Docker Compose

## Запуск

```bash
docker compose up --build
```

Застосунок доступний за адресою http://localhost:8000

## Налаштування

| Змінна | Значення за замовчуванням | Опис |
|---|---|---|
| `MAX_N` | 3000 | максимальна кількість невідомих |
| `MAX_N_MANUAL` | 20 | максимальна кількість невідомих при ручному введенні |
| `TIME_LIMIT_SECONDS` | 60 | максимальний час обчислення однієї задачі |
| `MAX_ACTIVE_TASKS` | 3 | кількість одночасних задач одного користувача |
| `MAX_HISTORY` | 50 | кількість задач в історії користувача |
| `WORKER_SLOTS` | 2 | кількість задач, що одночасно виконуються на сервері |
| `SERVER_NAME` | ім'я хоста | назва сервера застосунку |
| `SECRET_KEY` | — | ключ підпису JWT |

## API

| Метод | Шлях | Опис |
|---|---|---|
| POST | `/api/auth/register` | реєстрація |
| POST | `/api/auth/login` | вхід |
| GET | `/api/auth/me` | поточний користувач |
| GET | `/api/limits` | обмеження задач |
| POST | `/api/tasks` | створення задачі |
| GET | `/api/tasks` | історія задач |
| GET | `/api/tasks/{id}` | стан і результат задачі |
| POST | `/api/tasks/{id}/cancel` | скасування задачі |
